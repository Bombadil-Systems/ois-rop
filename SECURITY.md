# Security Policy

## Purpose

OIS-ROP is a security research tool that demonstrates how arbitrary payloads can be expressed as coordinate references into signed system binaries. It is intended for security research, red team tool development, and analysis of detection gaps in static scanning approaches.

## Reporting Vulnerabilities

If you discover a security vulnerability in OIS-ROP itself, please report it to: security@bombadil.systems

## Responsible Disclosure

If you use OIS-ROP to discover detection gaps in security products, please follow responsible disclosure practices and report findings to the affected vendors before public disclosure.
